# Свой домен для штаба — как переехать с sasok22873.github.io

Сейчас адрес выглядит так: `https://sasok22873.github.io/priznaki/`.
Убрать `sasok22873` и лишние символы можно только одним способом — **свой домен**.
GitHub Pages бесплатно даёт только поддомен с логином, изменить это нельзя.

Ниже — три варианта и полный чек-лист переезда. После покупки домена всё
настраивается за 10–15 минут, сайт не ломается: старый адрес можно оставить
рабочим или настроить переадресацию.

---

## Вариант 1 (рекомендую): свой домен .ru

Примеры, которые проверены как свободные или почти свободные:

| Домен | Вид ссылки | Цена в год |
|---|---|---|
| `priznaki24.ru` | `https://priznaki24.ru` | ~200–350 ₽ |
| `priznaki-beshenstva.ru` | `https://priznaki-beshenstva.ru` | ~200–350 ₽ |
| `pb24.ru` — занят | — | — |

Где купить:
- reg.ru: https://www.reg.ru/domain/new/
- timeweb: https://timeweb.com/ru/services/domains/

Покупка: выбираете домен → «Купить» → оплата картой → домен привязан к аккаунту.
Ничего больше делать не нужно — остальное настраиваю я.

## Вариант 2 (бесплатно, но с ожиданием): поддомен у сервиса разработчиков

- `priznaki24.is-a.dev` — заявка через GitHub PR: https://github.com/is-a-dev/register
- `priznaki24.js.org` — заявка через GitHub PR: https://github.com/js-org/js.org

Плюс: 0 ₽. Минус: одобрение 1–7 дней, и домен принадлежит сервису — если сервис
закроется, адрес пропадёт. Для рабочего штаба это риск.

## Вариант 3 (не подходит): бесплатные *.dev / *.app

Имена `priznaki24.dev` и `priznaki24.app` действительно свободны, но это платные
зоны (~$12/год ≈ 1000 ₽). То есть бесплатно не получится, а цена дороже .ru.

## Что произойдёт после переезда

У сайта будет один короткий адрес, например `https://priznaki24.ru`.
Внутри ничего не меняется — все данные, входы и роли остаются.

## Чек-лист для меня (после покупки домена)

1. DNS у регистратора:
   - `A` для `@` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` для `www` → `sasok22873.github.io`
2. В репозитории `priznaki` добавить файл `CNAME` с доменом.
3. В GitHub: Settings → Pages → Custom domain → вписать домен → включить **Enforce HTTPS**.
4. Дождаться сертификата (до 30 минут) и проверить `https://домен` и `https://www.домен`.
5. Обновить секрет Supabase `APP_REDIRECT_URL` на новый адрес — чтобы письма-приглашения
   и подтверждение почты вели на новый домен.
6. Проверить вход, приглашения, выход и восстановление сессии на новом адресе.
7. Обновить адреса в инструкциях (`TEAM_ACCESS_SETUP_RU.md`, `SOCIAL_API_SETUP_RU.md`, `TODO.md`).
8. Старый адрес `sasok22873.github.io/priznaki` можно оставить рабочим
   (GitHub сам редиректит на новый домен) — ничего не потеряется.

3. Всё остальное делаю я и присылаю отчёт со скриншотами.
