## Риски и решения

| Риск | Решение |
|---|---|
| Prisma + Supabase pooler | использовать `?pgbouncer=true&connection_limit=1` для serverless-сред, либо direct 5432 |
| Auth переезжает на Keycloak | API проверяет JWT Keycloak по JWKS; realm и роли импортируются, пользователи создаются в Keycloak |
| Дубль логики во время миграции | старый сайт не трогаем; новые фичи только в v2 |
| Данные пишутся из двух приложений | одинаковые таблицы и маппинг статусов; переход по домену после паритета |
| Мобильная сборка | EAS Build; в CI пока только typecheck/линт |
