# Подключение статистики соцсетей — пошагово

Документ для владельца: какие ключи нужны, где их взять и что делать с ними дальше.
**Важно:** ключи и токены — это пароли. В чат их не вставляйте и в GitHub не коммитьте.
Складывайте в файл `_secrets\social.txt` (см. раздел «Куда положить» в конце).

Что важно понимать сразу:

| Площадка | Что даёт API | Сложность |
|---|---|---|
| YouTube | подписчики, просмотры канала, список видео и их просмотры | легко (ключ) |
| ВКонтакте | участники, записи, просмотры записей | легко (сервисный ключ) |
| Telegram | количество подписчиков канала, название | легко (бот + админ канала) |
| TikTok | подписчики, лайки, список видео своего аккаунта | средне (OAuth) |
| Instagram | подписчики, публикации, охваты | сложно (Meta-приложение) |
| Spotify / Apple Music / Яндекс Музыка | публичного API для артиста нет | только вручную |

## 1. YouTube — API-ключ (5 минут, самый простой)

Ссылки:
- Google Cloud Console: https://console.cloud.google.com/
- Библиотека API: https://console.cloud.google.com/apis/library/youtube.googleapis.com
- Ключи: https://console.cloud.google.com/apis/credentials

Шаги:
1. Войдите в Google Cloud Console тем аккаунтом, который ведёт канал.
2. Сверху создайте проект: «Выбрать проект» → «Создать проект» → имя `priznaki-stats` → «Создать».
3. Откройте «Библиотека API» (ссылка выше) → найдите **YouTube Data API v3** → **Включить**.
4. Меню слева → **APIs & Services → Credentials** → **+ Создать учётные данные** → **API-ключ**.
5. Скопируйте ключ (начинается с `AIza...`).
6. Нажмите **Restrict key**:
   - «Application restrictions» → **HTTP referrers (web sites)** → добавьте `https://sasok22873.github.io/*`;
   - «API restrictions» → **Restrict key** → отметьте только **YouTube Data API v3**;
   - «Сохранить».
7. Пришлите: **API-ключ** и ссылку на канал (уже есть: @PRIZNAKI_BECHENSTVA).

Что получим: подписчики, суммарные просмотры канала, количество видео, последние видео и просмотры по каждому.

## 2. ВКонтакте — сервисный ключ (5 минут)

Ссылки:
- Сообщество: https://vk.ru/priznaki_beshenstva
- Документация: https://dev.vk.ru/ru/api/access-token/community-token
- (портал разработчика переехал с dev.vk.com на dev.vk.ru)

Шаги:
1. Откройте сообщество https://vk.ru/priznaki_beshenstva (нужны права администратора).
2. Справа: **Управление** → **Дополнительно** → **Работа с API**.
3. Вкладка **Ключи доступа** → **Создать ключ**.
4. Отметьте права: **Статистика** (stats), **Стена** (wall), при наличии — «Группы» (groups).
5. **Создать** → подтвердите в мобильном приложении ВК или по СМС.
6. Скопируйте ключ доступа сообщества (обычно начинается с `vk1.a.`).

Что получим: подписчики сообщества, последние записи, просмотры записей.
Полные охваты ВК отдаёт только через пользовательский токен (OAuth), поэтому стартуем с этих цифр.

Примечание: Implicit/Authorization Code Flow для пользовательских токенов ВК отключил в 2024,
поэтому путь через «Сервисный ключ доступа» приложения больше не нужен — ключ сообщества проще.

## 3. Telegram — бот + админ канала (5 минут)

Ссылки:
- BotFather: https://t.me/BotFather
- Документация Bot API: https://core.telegram.org/bots/api

Шаги:
1. Откройте в Telegram **@BotFather** → `/newbot` → имя `priznaki_stats_bot` → username, заканчивающийся на `_bot`.
2. BotFather покажет **токен** вида `1234567890:AA...` — скопируйте.
3. Откройте свой канал @PRIZNAKI_BECHENSTVA → «Управление» → «Администраторы» → «Добавить администратора» → найдите своего бота → дайте право «Просмотр участников» (и «Публикация», если не жалко).
4. Пришлите: **токен бота**.

Что получим: количество подписчиков канала, название, описание. Просмотры по постам Telegram через Bot API не отдаёт — их вносим вручную.

## 4. TikTok — OAuth-приложение (20–30 минут)

Ссылки:
- Портал разработчика: https://developers.tiktok.com/
- Мои приложения: https://developers.tiktok.com/apps
- Login Kit: https://developers.tiktok.com/doc/login-kit-web

Шаги:
1. Зарегистрируйтесь на https://developers.tiktok.com/ (вход через TikTok-аккаунт @priznakibeshenstva).
2. **Manage apps** → **Connect an app** → имя `priznaki-stats` → создать.
3. В приложении добавьте продукт **Login Kit** (и **Display API**, если предлагается).
4. В настройках Login Kit укажите **Redirect URI**: `https://sasok22873.github.io/priznaki/`
5. Возьмите **Client key** и **Client secret** из настроек приложения.
6. Пришлите: **Client key** и **Client secret**.

Что получим: подписчики, общее число лайков, список последних видео (просмотры по видео — по возможности).

Если TikTok затянет модерацию — не блокируйтесь: цифры по TikTok можно вносить вручную, API подключим позже.

## 5. Instagram — сложно, по желанию (30–60 минут)

Ссылки:
- Приложения Meta: https://developers.facebook.com/apps/
- Документация Instagram: https://developers.facebook.com/docs/instagram-platform

Что нужно знать: публичного API «просто по логину» нет. Нужен аккаунт **Professional (Business/Creator)** и приложение Meta.

Шаги:
1. Переключите Instagram @priznaki_bechenstva на **профессиональный** аккаунт (в приложении: Настройки → Аккаунт → Переключиться на профессиональный).
2. Привяжите его к странице Facebook (Настройки → Аккаунт → Связанные аккаунты).
3. Откройте https://developers.facebook.com/apps/ → **Create app** → тип **Business** → имя `priznaki-stats`.
4. Добавьте продукт **Instagram** → **API setup with Instagram login**.
5. Добавьте себя в роли: App roles → Instagram testers (или админ).
6. Получите **Long-lived access token** и **Instagram user id** (в панели API setup есть кнопка генерации токена).
7. Пришлите: **токен** и **id аккаунта**.

Что получим: подписчики, число публикаций, охваты по последним постам.
**Если не хочется возиться — скажите, оставим Instagram на ручном вводе.** Это нормальный вариант.

## 6. Стриминги — только вручную

Публичного API, который отдаёт артисту прослушивания, у Spotify, Apple Music и Яндекс Музыки нет.

- Spotify for Artists: https://artists.spotify.com/
- Apple Music for Artists: https://artists.apple.com/
- Яндекс Музыка для артистов: https://music.yandex.ru/

Раз в неделю (или в день, как решите) открываете кабинет артиста и вносите цифры в приложении: прослушивания, слушатели, подписчики.

## Куда положить ключи

Создайте файл:

```
C:\Users\MAINPEKA\Documents\deepseek-harness\default-workspace\_secrets\social.txt
```

Внутри — только нужные строки, без кавычек:

```
youtube_api_key=AIza...
vk_service_token=...
telegram_bot_token=1234567890:AA...
tiktok_client_key=...
tiktok_client_secret=...
instagram_token=...
instagram_user_id=...
```

Что не получилось — просто не добавляйте строку. После настройки скажите «готово»: я перенесу значения в защищённые секреты Supabase и **удалю файл**.
